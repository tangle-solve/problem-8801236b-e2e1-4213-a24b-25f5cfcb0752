### CHEM-000229: Uniform outer-electron radius bound
- **Subfield:** Round 2
- **Open:** Define \(R_m(Z)\) so that a fixed number \(m>0\) of electrons lie outside that radius in a neutral atom. Establish \(Z\)-independent bounds, with the appropriate dependence on \(m\), for the full interacting theory.
- **Status:** Corresponding Hartree–Fock ionization-radius results are proved. Comparable exact many-electron density-tail control remains a decades-old problem.
- **Type:** theory
- **Why:** Explains why chemically relevant valence length scales need not shrink with the atomic core.
- **Key works:** J. P. Solovej (2003), *The Ionization Conjecture in Hartree-Fock Theory*, [arXiv:math-ph/0012026](https://arxiv.org/abs/math-ph/0012026).
- **Related:** PDE: decay estimates for many-particle eigenfunctions; spectral theory: threshold states.
